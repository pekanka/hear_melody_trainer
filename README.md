# Тренажёр мелодий на слух

Небольшое настольное приложение для практики подбора мелодий и аккордов на гитаре. Оно создаёт упражнение, проигрывает его и скрывает ответ до нажатия кнопки «Показать ответ».

## Возможности

- Случайная или выбранная тоника; мажор и натуральный минор.
- Размер 2/4, 3/4 или 4/4; число тактов (1–16) и темп (40–240 BPM) вводятся вручную.
- Мелодии с тремя уровнями сложности или последовательности аккордов из диатонических трезвучий.
- Смена аккордов каждый такт, раз в два такта или случайно через один-два такта.
- Названия нот «C–D–E» по умолчанию или «До–Ре–Ми», повторное прослушивание и остановка воспроизведения.
- Скрытый до проверки ответ: ноты и длительности мелодии либо аккорды, ступени и их звуки.

## Запуск

Нужны Windows и Python 3.10+ с Tkinter. Сторонние пакеты не требуются.

```powershell
python melody_ear_trainer.py
```

Файл `start training.cmd` запускает приложение через локальную установку Python, путь к которой указан внутри файла. На другом компьютере используйте команду выше или измените этот путь.


## Как заниматься

Для мелодий начните с одного такта на уровне «Легко»: прослушайте, напойте и найдите ноты на гитаре. Для аккордов начните с четырёх тактов со сменой каждый такт; попробуйте сначала услышать басовую ноту, а затем определить мажорное, минорное или уменьшённое трезвучие. После попытки откройте ответ и сравните.
