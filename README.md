# Тренажёр слуха

Приложение для практики подбора мелодий и аккордов на гитаре. Оно создаёт упражнение, проигрывает его и скрывает ответ до нажатия кнопки «Показать ответ». Версия для Windows написана на Python; Android-версия находится в папке `android/`.

## Возможности

- Случайная или выбранная тоника. Для мелодий доступны семь диатонических ладов: мажор (ионийский), дорийский, фригийский, лидийский, миксолидийский, минор (эолийский) и локрийский. Для аккордов — мажор и натуральный минор.
- Размер 2/4, 3/4 или 4/4; число тактов (1–16) и темп (40–240 BPM) вводятся вручную.
- Три режима: мелодия, последовательность аккордов из диатонических трезвучий или аккорды с одновременно звучащей мелодией. В совместном режиме мелодия опирается на ноты текущего аккорда на сильных долях.
- Три уровня сложности мелодии.
- Три уровня для отдельного режима аккордов: «Легко» сохраняет прежние трезвучия в одном регистре с опорой на I ступень; «Обычно» добавляет связные переходы и смену регистра; «Сложнее» расширяет диапазон и добавляет обращения трезвучий. В ответе для обращения показываются исходный аккорд и басовая нота через `/`.
- Смена аккордов каждый такт, раз в два такта или случайно через один-два такта.
- Названия нот «C–D–E» по умолчанию или «До–Ре–Ми», повторное прослушивание и остановка воспроизведения.
- Скрытый до проверки ответ: ноты и длительности мелодии, аккорды со ступенями и их звуками или обе партии по отдельности.

## Windows

Нужны Windows и Python 3.10+ с Tkinter. Сторонние пакеты не требуются.

```powershell
python melody_ear_trainer.py
```

Файл `start training.cmd` запускает приложение через локальную установку Python, путь к которой указан внутри файла. На другом компьютере используйте команду выше или измените этот путь.

`logo.png` — исходное изображение. Многомерный `logo.ico` содержит варианты для маленьких значков Windows и включается в `.exe` при сборке релиза.

## Android: тестовая версия

Откройте папку `android/` как проект в Android Studio. После установки Android SDK 35 выберите эмулятор или подключённый телефон и нажмите **Run**. Для установки на телефон без Android Studio соберите `app-debug.apk` через **Build → Build APK(s)**.

Если Android Studio пока нет, после отправки изменений в ветку `indev` откройте вкладку **Actions → Build Android preview**. В завершённом запуске скачайте артефакт `MelodyEarTrainer-android-preview`: внутри будет оптимизированный тестовый APK. Рабочий процесс также запускается вручную через **Run workflow**. Обычный push в `main` тестовую Android-сборку не запускает. В Android Studio кнопка **Run** по умолчанию запускает отладочную сборку; для проверки плавности используйте APK из Actions или соберите `preview` через Gradle.

При отправке нового тега `v*` процесс **Build Windows and Android release** собирает оба приложения из одного и того же тега и прикрепляет `MelodyEarTrainer.exe` и `MelodyEarTrainer-android-preview.apk` к одному релизу GitHub. Релиз публикуется только после успешной сборки обеих версий. Сначала отправьте коммит с изменениями, а затем создайте и отправьте новый тег на этот коммит.

Android-версия поддерживает те же режимы и параметры упражнений, повторное прослушивание, остановку и скрытый ответ. Настройки прокручиваются на небольшом экране. Тестовый APK подписывается отладочным ключом; для постоянных релизов и обновления приложения без переустановки позже понадобится отдельный постоянный ключ подписи.


## Как заниматься

Для мелодий начните с одного такта на уровне «Легко»: прослушайте, напойте и найдите ноты на гитаре. Для аккордов начните с четырёх тактов со сменой каждый такт; попробуйте сначала услышать басовую ноту, а затем определить мажорное, минорное или уменьшённое трезвучие. В совместном режиме попробуйте сначала определить аккорды, а потом напеть и подобрать мелодию на их фоне. После попытки откройте ответ и сравните.
