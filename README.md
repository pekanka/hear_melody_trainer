# Тренажёр мелодий на слух

Небольшое настольное приложение для практики подбора мелодий на гитаре. Оно создаёт короткую случайную мелодию, проигрывает её и скрывает ноты до нажатия кнопки «Показать ответ».

## Возможности

- Случайная или выбранная тоника; мажор и натуральный минор.
- Размер 2/4, 3/4 или 4/4, выбор числа тактов и темпа.
- Три уровня сложности, повторное прослушивание и остановка воспроизведения.
- Ответ с нотами, октавами и длительностями по тактам.

## Запуск

Нужны Windows и Python 3.10+ с Tkinter. Сторонние пакеты не требуются.

```powershell
python melody_ear_trainer.py
```

Файл `start training.cmd` запускает приложение через локальную установку Python, путь к которой указан внутри файла. На другом компьютере используйте команду выше или измените этот путь.

## Готовый файл для Windows

После публикации версии скачайте `MelodyEarTrainer.exe` на странице [Releases](https://github.com/pekanka/hear_melody_trainer/releases). Для запуска Python не нужен. Файлы `Source code` на той же странице содержат только исходники. Другу можно отправить [ссылку на последнюю версию](https://github.com/pekanka/hear_melody_trainer/releases/latest).

Новый релиз создаётся автоматически после отправки тега версии в GitHub:

```powershell
git tag v0.1.0
git push origin v0.1.0
```

Перед этим сохраните и отправьте изменения программы в ветку `main`. Сборка появится на вкладке **Actions**, а готовый файл — на странице **Releases**. Для следующей версии используйте новый тег, например `v0.2.0`; старые релизы сохранятся. Тег ставьте на тот коммит, который хотите выпустить.

Для проверки сборки на своём Windows-компьютере можно выполнить:

```powershell
python -m pip install pyinstaller==6.22.3
python -m PyInstaller --onefile --windowed --name MelodyEarTrainer melody_ear_trainer.py
```

Файл появится в `dist/MelodyEarTrainer.exe`. Папка `dist` не добавляется в Git.

## Как заниматься

Начните с одного такта на уровне «Легко». Прослушайте мелодию, попробуйте её напеть и найти ноты на гитаре. Затем откройте ответ и сравните. Когда короткие фразы станут даваться уверенно, увеличивайте число тактов и сложность.
